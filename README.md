# RED BUL — متجر المنتجات الرقمية

متجر عربي بتصميم أسود وأحمر، يتضمن كتالوج منتجات وسلة مشتريات ولوحة إدارة محمية وإدارة طلبات ونظام توليد رخص وأكواد تفعيل.

## المتطلبات
- Node.js 20+
- PostgreSQL
- Git (للنشر على GitHub)

## تشغيل محلي
1. ثبّت Node.js وPostgreSQL.
2. انسخ `.env.example` إلى `.env`.
3. عدّل `DATABASE_URL` ليطابق قاعدة بيانات PostgreSQL المحلية.
4. غيّر `SESSION_SECRET` و`ADMIN_PASSWORD` إلى قيم قوية خاصة بك.
5. شغّل:
   ```bash
   npm install
   npm start
   ```
6. افتح `http://localhost:10000`، ولوحة الإدارة عبر `/admin`.

## النشر على Render
يوجد `render.yaml` لتجهيز Web Service وقاعدة PostgreSQL. ارفع المشروع إلى GitHub، ثم في Render اختر **New > Blueprint** واربط المستودع. عند طلب القيم، أضف:
- `ADMIN_USERNAME`: اسم مستخدم المدير.
- `ADMIN_PASSWORD`: كلمة مرور قوية وفريدة.
- `BASE_URL`: رابط الموقع المنشور، مثل `https://اسم-الخدمة.onrender.com`.

تحقق من أن `DATABASE_URL` مربوط بقاعدة PostgreSQL التي أنشأها الـ Blueprint. لا ترفع ملف `.env` إلى GitHub ولا تضع مفاتيح سرية في ملفات الواجهة.

## الدفع الإلكتروني
الدفع اليدوي يعمل كمسار تسجيل طلب. لتفعيل Stripe:
1. أضف `STRIPE_SECRET_KEY` في Environment Variables في Render.
2. أضف `STRIPE_WEBHOOK_SECRET` بعد إنشاء webhook في لوحة Stripe يشير إلى `https://YOUR-DOMAIN/api/stripe/webhook`، مع حدث `checkout.session.completed`.
3. اضبط `BASE_URL` على عنوان الموقع الحقيقي وأعد النشر.
4. اختبر في وضع الاختبار قبل تفعيل المدفوعات الحقيقية.

لا تُسلّم الطلبات اعتمادًا على صفحة نجاح المتصفح وحدها؛ حالة الدفع تُحدّث عبر webhook. تحقق من أهلية حساب التاجر والقيود المحلية قبل تفعيل المدفوعات.

## الصور والتخزين الدائم
رفع الصور يحفظها في مجلد `uploads`. في Render، التخزين المحلي قد لا يبقى بعد إعادة النشر/تبديل الخدمة ما لم تضبط Persistent Disk على `/opt/render/project/src/uploads` (وتأكد من مسار المشروع)، أو تستبدل التخزين بخدمة صور دائمة. قاعدة PostgreSQL تحفظ المنتجات والطلبات والرخص.

## ملاحظات أمنية مهمة
- غيّر كلمة مرور المدير قبل النشر.
- لا تشارك متغيرات البيئة أو مفاتيح Stripe.
- استخدم الأكواد والرخص لمنتجاتك وخدماتك أو المنتجات التي تملك إذنًا ببيعها فقط.
- الرخص التي ينشئها النظام هي أكواد لمتجرك؛ لا تنشئ اشتراكات لطرف ثالث دون تفويض.
- هذه نقطة بداية قابلة للتطوير وليست تدقيقًا أمنيًا أو مراجعة امتثال نهائية.
